# DeviceDesk

DeviceDesk is a site for managing an organization's IT equipment .

## Features

120 starter devices from the generated API
Search by device name or inventory number(INV-008 for example).
Filter by device type, status, and location.
Sort by bought date or cost and browse with pagination.
Open a device info and add a new device with a controlled form.
Loading, error, empty, and success states for the devices.
Responsive layout for desktop and mobile.
